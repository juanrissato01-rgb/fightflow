# 🥊 FightFlow

App web simples para professores de luta gerenciarem alunos e mensalidades.

## Funcionalidades

- Cadastro de alunos (nome, modalidade, WhatsApp, valor da mensalidade, dia de vencimento)
- Status automático por mês: **Pago**, **Pendente** ou **Atrasado**
- Resumo do mês: total recebido, pendente e atrasado
- Navegação entre meses para ver o histórico
- Botão de cobrança que abre o WhatsApp com mensagem pronta
- Busca e filtro por status
- Exportar/importar backup em JSON

## Como usar

Acesse o site pelo GitHub Pages ou abra o `index.html` no navegador. Não precisa de instalação.

Os dados ficam salvos no `localStorage` do navegador — ou seja, apenas no aparelho onde foram cadastrados. Use **Exportar backup** regularmente.
